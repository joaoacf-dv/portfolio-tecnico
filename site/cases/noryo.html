Noryo — Utility Portal

Portal público de utilitários web orientado a tarefas rápidas, com execução estática, experiência bilíngue e processamento no navegador sempre que o fluxo permite.

Em produção
Next.js React TypeScript Vitest pdf-lib

Visão Geral

O Noryo é um produto web de utilidades organizado como portal público, com catálogo de ferramentas, rotas em português e inglês e arquitetura preparada para expansão incremental sem exigir backend para as operações client-side.

Solução Desenvolvida

A aplicação utiliza Next.js e TypeScript com geração estática. Nos fluxos compatíveis, arquivos são processados diretamente no navegador, reduzindo dependência de infraestrutura de backend e mantendo o caminho de execução simples.

Arquitetura / Fluxo

Entrada do usuário
Interface web
Processamento client-side

Resultado

Entregas Técnicas

  • Catálogo de utilitários com rotas públicas estáticas.
  • Experiência bilíngue PT-BR e EN.
  • PDF Core com juntar PDF, dividir PDF e JPG para PDF processados no cliente.
  • Testes automatizados, lint, typecheck, build e smoke de navegador como gates de entrega.

Competências Demonstradas

  • Arquitetura frontend com Next.js, React e TypeScript.
  • Processamento binário client-side e manipulação de PDF.
  • SEO técnico, rotas estáticas e internacionalização.
  • Disciplina de release com regressão, evidência e rollback preservado.

Resultado Técnico

O projeto demonstra construção e operação de um produto web público enxuto, extensível e orientado a desempenho, com funcionalidades reais executadas diretamente no navegador.
